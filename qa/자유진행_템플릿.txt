# 자유 진행 템플릿 — 추천답변 / 랜덤답변 / 이어서 생성 / 섞기
# 유저가 무엇을 하든(또는 아무것도 안 하든) 세상·사건이 스스로 굴러가는지 본다.
# 패널의 "턴 준비" 버튼을 쓸 때는 이 파일의 설정(@hud·@watch·@gap·@pool)만 빌려 쓴다.
# 이 파일 자체를 돌리면 아래 @repeat 블록대로 진행한다.

@meta 이름=자유진행 | 모델= | 시나리오=

# 응답 끝나고 1~5초 무작위 + 응답 1000자당 3초
@gap 1-5
@read 3

# 상태 주석 칸 이름 (작품마다 다름. 모르면 지워도 됨)
# @hud 날짜|장소|사건

# 등장하면 O 로 찍을 단어 (NPC 이름, 사건 키워드 등)
# @watch 갑|을

# [랜덤] 문장 풀. 이 블록을 지우면 기본 풀(약 1,000개)을 쓴다.
@pool
...
*가만히 지켜본다.*
응.
싫어.
왜?
*자리를 뜬다.*
*주변을 둘러본다.*
그래서 어떻게 됐어?
@end

# [이어서] 버튼이 없을 때 대신 보낼 것 (off 면 그 턴 실패 처리)
# @continue *아무 말 없이 기다린다.*

# 매 턴 셋 중 무작위로 30턴
@repeat 30
[섞기]
@end

# @end
