# 크랙 툴박스

크랙(crack.wrtn.ai) 작품을 만들고 점검할 때 쓰는 도구 세 가지를 하나로 합친 크롬 확장 프로그램이에요. (비공식)

- **TXT 자동 입력** — 스토리 수정 화면에 main·start·keyword·shortcut·media 파일을 자동으로 넣어요. 플레이가이드(`…_플레이가이드.md`)와 추천 답변(`…_추천답변.md`)도 같이 넣어요.
- **QA 러너** — 채팅 화면에서 추천답변·랜덤답변·이어서 생성으로 턴을 넘기고, 응답 원문과 상태 주석을 CSV/MD로 내보내요.
- **버전 설정** — 스토리 수정 화면에서 한 줄 소개를 눈에 띄지 않게 바꿔 저장하는 과정을 반복해 목표 버전까지 올려요.
- 새 버전이 나오면 팝업에 **새 버전 업데이트** 버튼이 뜨고, 버튼 하나로 바뀐 파일만 받아서 바꿔 넣어요.

예전의 「크랙 TXT 자동 입력기」「Crack QA 러너」「크랙 버전 설정」를 따로 쓰고 있었다면, 툴박스를 설치한 뒤 그 셋은 꺼 주세요. 같이 켜 두면 패널이 두 개씩 떠요.

## 설치

1. 오른쪽 위 초록색 **Code → Download ZIP**으로 받아서 압축을 풀어요. 풀린 폴더는 지우지 않을 곳에 둬요.
2. 크롬 주소창에 `chrome://extensions` (엣지는 `edge://extensions`, 웨일은 `whale://extensions`)
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** → 풀린 폴더(`manifest.json`이 들어 있는 폴더)를 고르기
5. 퍼즐 아이콘에서 크랙 툴박스를 고정해 두면 편해요

## 쓰는 법

툴바의 아이콘을 누르면 팝업이 열려요.

### TXT 자동 입력

1. 크랙 **내 작품 → 작품 [⋯] → 수정하기**로 스토리 수정 화면을 열어요.
2. 팝업의 **이미 만든 파일 넣기**에 파일을 한꺼번에 골라요. 파일 이름으로 종류를 알아봐요.

   | 파일 이름에 들어 있는 말 | 넣는 곳 |
   |---|---|
   | `main` | 스토리 설정 |
   | `start` | 시작 설정 (프롤로그·시작 상황·이름) |
   | `플레이가이드` | 시작 설정 → 고급 설정 → 플레이 가이드 (칸마다 500자) |
   | `추천답변` | 시작 설정 → 고급 설정 → 추천 답변 (최대 3개, 칸마다 200자) |
   | `keyword` | 키워드북 |
   | `shortcut` | 단축어 |
   | `media` | 미디어 |

3. **있는 항목만 자동 입력**을 눌러요. 화면 오른쪽 아래에 진행 창이 떠요.
4. 다 되면 내용을 확인하고 상단 **수정**을 직접 눌러 저장해요. 툴박스는 저장 버튼을 누르지 않아요.

플레이가이드·추천답변 파일은 이런 모양이에요.

```
## 시작설정 이름
플레이가이드 본문…

## 다음 시작설정 이름
…
```

```
## 시작설정 이름
### 1
첫 번째 추천 답변
### 2
두 번째 추천 답변
### 3
세 번째 추천 답변
```

- `start` 파일과 같이 고르면 시작 설정 이름이 같은 탭에 넣어요. 이름이 다르면 파일에 적힌 순서대로 넣어요.
- `start` 없이 플레이가이드·추천답변만 고르면, 이미 있는 시작 설정 탭에 그 두 가지만 넣고 프롤로그·시작 상황은 건드리지 않아요.
- 추천 답변은 파일에 있는 개수로 맞춰요(남는 칸은 지워요).

### QA 러너

채팅 화면에서 팝업의 **QA 러너 → 열기**를 누르면 패널이 열리고, 한 번 더 누르면 닫혀요.

### 버전 설정

스토리 수정 화면 오른쪽 위의 **버전 설정** 버튼을 누르거나, 팝업의 **버전 설정 → 열기**를 눌러요. 모든 저장이 크랙의 「업데이트 정보」에 버전 기록으로 남아요. 버전 숫자를 부풀리는 건 크랙 운영 정책상 문제가 될 수 있으니 본인 판단으로 쓰세요.

## 업데이트

새 버전이 나오면 팝업 오른쪽 위에 **새 버전 업데이트** 버튼이 떠요. 누르고, 처음 한 번만 툴박스가 설치된 폴더를 골라 주면 바뀐 파일만 받아서 바꿔 넣고 다시 켜져요. 설정은 그대로예요. 팝업 맨 아래 **업데이트 확인**으로 바로 확인할 수도 있어요.

## 주의

- 크랙 화면이 바뀌면 동작하지 않을 수 있어요. 그럴 땐 무엇을 못 찾았는지 알려 주고 멈춰요.
- 자동 입력 중에는 크롬에 「디버깅 중」 안내가 떠요. 사람이 누른 것과 같은 클릭을 만들려고 쓰는 것이고, 끝나면 사라져요.

## 바뀐 점

## v1.0.0 — 세 도구를 하나로
- TXT 자동 입력·QA 러너·버전 설정을 한 확장 프로그램으로 합쳤어요
- 플레이가이드와 추천 답변 파일을 자동으로 넣어요
- 팝업·진행 창·버전 설정 창을 다른 확장 프로그램과 같은 모양(밝은/어두운 화면)으로 바꿨어요
- 새 버전이 나오면 알려 주고, 버튼 하나로 업데이트해요
- 「GPT에 자료 주기」(ChatGPT 창을 열어 파일을 만들게 하던 기능)는 뺐어요. 이미 만든 파일을 넣는 기능만 남아요
- 「버전 올리기」의 이름을 「버전 설정」으로 바꿨어요
